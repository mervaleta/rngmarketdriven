Propiedades

mm / pt
01 / Documento

El calibre es el grosor de una hoja física; el lomo estimado usa la mitad de páginas × calibre. Impresora, papel y encuadernación determinan el valor real.

02 / Tipografía

Se usan familias de fuentes instaladas en el dispositivo; un nombre ausente podrá mostrarse con fuente de sustitución. La composición definitiva necesita pruebas de fuentes y licencia.

03 / Mancha y márgenes
04 / Cubierta y datos

Podés probar una imagen local. No se envía a un servidor ni se incorpora al respaldo JSON. Usar imágenes con derechos verificados.

05 / Texto de muestra editable

El contenido se repite en las vistas de prueba para visualizar blancos y tamaños. No se pagina íntegramente ni se exporta como libro final.
