Diseñador de maquetación

El libro completo en pliegos, con aperturas de capítulo a doble página, separador para notas y ajustes finos de lectura y tipografía.

M04 · APERTURAS TIPOGRÁFICAS
La grilla incluye automáticamente la transcripción completa en inglés de 1884, dividida en prefacio, cuatro ensayos y posdata. Los extras mantienen sus estimaciones. La distribución tipográfica sigue siendo aproximada. Los ejemplos textuales y folios son ilustrativos.

Propiedades

mm / pt
01 / Documento

El calibre es el grosor de una hoja física; el lomo estimado usa la mitad de páginas × calibre. Impresora, papel y encuadernación determinan el valor real.

02 / Tipografía

Montserrat se carga desde Google Fonts (pesos 100–900, normal y cursiva, licencia OFL). Otras familias dependen del equipo. Verificar las fuentes incrustadas en el PDF final.

03 / Mancha y márgenes

Sin tope superior en márgenes, sangría ni sangrado. Si el espacio para texto no alcanza, se mostrará una advertencia.

04 / Aperturas de capítulo y notas

Un pliego a dos páginas por ensayo: izquierda ornamental y derecha con título de sección. También se aplica a las notas.

Si se inicia el texto en recto se agrega una página blanca real después del pliego. Las páginas de apertura y cortesía cuentan para el lomo.

05 / Cubierta y datos

Podés probar una imagen local. No se envía a un servidor ni se incorpora al respaldo JSON. Usar imágenes con derechos verificados.

06 / Texto de muestra para extras

Este campo sirve para probar el diseño de material complementario. El texto principal del libro se carga desde la transcripción inglesa completa de 1884; no depende de este relleno.

Los cambios se guardan en este navegador.
