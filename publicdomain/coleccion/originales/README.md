# Siglo23 — Textos originales de «El individuo y el poder»

**Versión de inventario:** 2026-11-06 · v0.4.0  
**Ámbito:** investigación y preproducción editorial, no lanzamiento comercial.

Aquí se conservan transcripciones en el idioma original de obras que se estudian para la colección. Los archivos **no son facsímiles**, ni transcripciones críticamente cotejadas con sus primeras ediciones. Se mantienen los encabezados, avisos de procedencia y condiciones asociadas a los archivos de Project Gutenberg/GITenberg.
