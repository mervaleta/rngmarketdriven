# Siglo23 / Materiales

Sección autónoma dentro de `publicdomain/materiales/`. El resto de `publicdomain/` se conserva.

Contiene 111 fichas temáticas, 13 categorías, 37 fuentes, 3 obras preliminares, 12 colecciones y 12 guías de derechos.

## Actualizar una ficha

Cada ítem tiene **su propio HTML**. Para editar su contenido visible basta modificar `items/SIG-XXXX-slug.html`, sin reconstruir el sitio. El registro correspondiente en `datos/items/SIG-XXXX.json` debe actualizarse en la misma modificación para conservar la trazabilidad. Idéntica regla para categorías, fuentes, obras, colecciones y licencias. Los estilos compartidos están en `assets/style.css`. Si se agregan fichas nuevas, crear HTML + JSON y enlazarlas desde el índice del grupo y su categoría.

## Derechos

Este banco contiene recomendaciones de búsqueda y estados preliminares. Ningún objeto se considera autorizado comercialmente sin verificación de fuente, derechos, territorio, fecha y potencial FNA argentino.

## Entrada

`/publicdomain/materiales/index.html` — enlazada desde `/publicdomain/recursos/index.html`.
