¿Cómo aprovechamos también el código y el diseño?

Cuando una ficha contiene «Download for ereaders», su EPUB se descarga individualmente sin coste. En «More details → This ebook’s source code at GitHub» puede estudiarse XHTML, CSS, notas, índice y metadatos para mejorar nuestras ediciones. La investigación puede cruzarse luego con Project Gutenberg y facsímiles de bibliotecas para cotejar el texto.
