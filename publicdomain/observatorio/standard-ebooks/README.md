# Standard Ebooks gratuito — Siglo23

Nueva sección: `/publicdomain/observatorio/standard-ebooks/`.

Se integra a la base central `/publicdomain/catalogo-global.json` (340 registros en revisión 2026-11-06) y ofrece un enlace para buscar **cada obra** usando la consulta pública `https://standardebooks.org/ebooks?query=<TITLE>`.

- El navegador descarga de nuestro servidor el JSON central; **no descarga en lote ebooks de terceros**.
- La búsqueda abre Standard Ebooks en nueva pestaña con query codificada.
- El editor marca manualmente si encontró un ebook individual descargable, una ficha pendiente o ningún resultado.
- Marcas guardadas en `localStorage`, con exportación CSV. No hay sincronización servidor de marcas.
- 7 fichas iniciales comprobadas: 5 descargables y 2 por producir. No trasladar estas 7 a lista de dominio público argentina aprobado.
- EPUB individual gratuito, XHTML/CSS en repositorios públicos; ZIP masivo y feeds OPDS completos sólo acceso autorizado.
- El catálogo `/ebooks` también incluye fichas de libros que aún no produjo. Nunca inferir disponibilidad por la sola existencia de una URL.
- Para permitir futura ingesta documental, crear una tabla por edición con URL del ejemplar, editor, edición, autor, idioma, libro original y estado jurídico por país.

Fuentes: https://standardebooks.org/bulk-downloads · https://standardebooks.org/ebooks · https://standardebooks.org/feeds · https://standardebooks.org/about
