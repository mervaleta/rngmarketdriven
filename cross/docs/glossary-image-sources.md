# Fuentes de imágenes de moda para Studio

## Clothing Dataset (selección aprobada)
- Repositorio: https://github.com/alexeygrigorev/clothing-dataset
- Revisión de origen: 7ed86a9cc56763b6acb35e41cb35184e43a5d218
- Licencia: https://github.com/alexeygrigorev/clothing-dataset/blob/7ed86a9cc56763b6acb35e41cb35184e43a5d218/LICENSE (CC0 1.0)
- Descripción de recolección: https://medium.com/data-science-insider/clothing-dataset-5b72cd7c3f1f
- CSV: 5403 filas, 4927 con kids=False. El atributo no identifica género ni garantiza que la imagen sea adecuada; revisión visual obligatoria.
- Se importan únicamente imágenes revisadas, sin personas identificables y con prendas claramente reconocibles. Las fotos tienen finalidad editorial, no son fotos de ofertas afiliadas.
- Archivos locales en cross/assets/glossary/clothing-dataset/; cada registro conserva el enlace exacto al original. La versión de GitHub está redimensionada y es suficiente para miniaturas.
- No se realiza importación masiva ni se asignan subtipos solo por etiquetas amplias.

## Otras fuentes (pendientes, no autorizadas para importación automática)
Women Clothing Images, Fashion Product Images (Small/HD), E-commerce Product Images: verificar procedencia y derechos de las fotos, no basta licencia declarada de dataset.
Fashionpedia: anotaciones y taxonomía útiles; revisar términos de cada fotografía original.
Atlas y Stylish Product Images: no redistribuir imágenes extraídas de tiendas sin permiso verificable.
Repositorios derivados: rastrear fuente original; no asumir licencia del código como licencia de fotos.
