# Publicar la biblioteca de Studio

La publicación del catálogo usa un paquete independiente de la vista previa HTML. El workflow **Publish Studio encyclopedia** construye un artefacto con las fichas, las 14 fotos ya locales y las referencias Commons disponibles descargadas como JPEG. Las referencias que no se pueden descargar se conservan con el mecanismo de proxy y se registran en image-report.json; no se inventan sustituciones. Se valida PHP antes de subir. El workflow utiliza FTPS con credenciales secretas preconfiguradas, nunca credenciales versionadas. Si no están disponibles, descargar el artefacto studio-encyclopedia-release y superponer el contenido de cross/ sobre la instalación existente desde hPanel, sin eliminar archivos no incluidos ni tocar private/. Verificar que includes y private estén protegidos antes de publicar. No usar el antiguo deploy.php para este catálogo: solo actualiza la vista previa. Configurar STUDIO_FTP_HOST, STUDIO_FTP_USER y STUDIO_FTP_PASSWORD en Settings > Secrets and variables > Actions; opcional STUDIO_FTP_ROOT (por defecto public_html/cross) y STUDIO_FTP_PORT. Verificar que la cuenta tenga acceso limitado a Studio.
